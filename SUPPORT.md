## Where to ask

Use this repository's GitHub Issues for:

- installation and onboarding problems;
- usage questions not answered by the documentation;
- reproducible software defects;
- documentation corrections;
- focused feature requests.

Search open and closed issues before filing a new one. Use one issue for one problem.

Do not use a public issue for:

- security vulnerabilities, exposed credentials, or private data: follow the [Security Policy](SECURITY.md);
- harassment or conduct concerns: follow the [Code of Conduct](CODE_OF_CONDUCT.md);
- general pull-request guidance: follow the [Contributing Guide](CONTRIBUTING.md).

## Information to include

Provide enough sanitized detail for another person to reproduce or understand the request:

- Gorombo Skill Harvester version or commit;
- operating system and installation method;
- selected route mode;
- the command or interface involved;
- expected and actual behavior;
- minimal reproduction steps;
- relevant logs with secrets, IDs, private content, and machine-specific paths removed.

For feature requests, describe the affected user or workflow, the problem being solved, and the desired outcome.

## Support boundaries

Gorombo Skill Harvester 0.1.x is maintained through its public repository on a best-effort basis. There is no guaranteed response or resolution time.

The project cannot provide support for unreviewed local modifications, unsupported runtime versions, third-party service outages, revoked or misconfigured credentials, or upstream products outside Gorombo Skill Harvester's control. A report is still useful when Gorombo Skill Harvester handles one of those conditions incorrectly.
